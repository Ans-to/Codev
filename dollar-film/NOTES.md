# Notes

- 30-second, 960×540, 24 fps landscape master, built from the included starter renderer. A smaller frame and fewer samples are used because this environment renders in software.
- No recorded voice: the film uses large on-screen narrative text and an original synthesized score.
- `film.js` is deterministic and can render isolated frames. See README.md for commands.
- Final encoded file checked: 720 frames, 30.00 seconds, H.264/AAC; integrated loudness −14.0 LUFS, true peak −1.5 dBTP. Playback on a physical phone was not available in this environment.
